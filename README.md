# Stock Portfolio Tracker

## About
This is a beginner-friendly Python project that calculates the total investment in different stocks.

## Features
- Displays available stocks and their prices
- Takes stock symbols and quantities from the user
- Calculates the investment for each stock
- Displays the total investment
- Saves the portfolio in a text file

## Technologies Used
- Python
- Dictionaries
- Lists
- Loops and conditions
- File handling

## How to Run
1. Install Python.
2. Download this repository to your computer.
3. Open a terminal in the project folder.
4. Run the following command:

   `python stock_tracker.py`

## Note
The stock prices are predefined example values and are not live market prices.
